=== صفحة اختبار الوعي السيبراني — تعليمات الرفع ===

الملفات:
  index.html   ← الصفحة
  preview.jpg  ← صورة المعاينة (منشور X)

قبل المشاركة على فيسبوك، لازم تعدّل مكان واحد فقط:
  افتح index.html وابحث عن __BASE__ (موجودة 3 مرات)
  بدّلها بعنوان موقعك بعد الرفع، بدون / في الآخر.
  مثال: https://jo-awareness.netlify.app

------------------------------------------------------------
الطريقة الأسهل — Netlify Drop (بدون تنصيب، مجاني):
 1) روح على:  https://app.netlify.com/drop
 2) اسحب مجلد x-awareness كامل وأفلته هناك.
 3) رح يعطيك رابط مثل:  https://random-name-123.netlify.app
 4) (اختياري) غيّر الاسم من Site settings > Change site name.
 5) ارجع عدّل __BASE__ في index.html لهذا الرابط، واسحب المجلد مرة ثانية (تحديث).
 6) جرّب المعاينة عبر: https://developers.facebook.com/tools/debug/
    الصق رابطك واضغط "Scrape Again".

------------------------------------------------------------
بديل — GitHub Pages (الرابط معروف من البداية):
 1) أنشئ Repo باسم مثلاً awareness، ارفع الملفين.
 2) Settings > Pages > Deploy from branch > main /(root).
 3) رابطك:  https://USERNAME.github.io/awareness
 4) حط هذا الرابط مكان __BASE__ قبل أو بعد الرفع (ثم اعمل commit).

------------------------------------------------------------
تذكير: للاستخدام الداخلي على فريقك المصرّح فقط.
الصفحة توعوية ولا تجمع أي بيانات.
